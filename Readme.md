# API Clima

Este es un proyecto profesional en Python diseñado para consultar el clima actual de diferentes ciudades utilizando la API de OpenWeather. Integra buenas prácticas de desarrollo como entornos virtuales, linters, formateadores de código y gestión de variables de entorno.

## Requisitos

Antes de comenzar, asegúrate de tener instalado:
* Python 3.10 o superior
* Una cuenta en OpenWeather (para obtener la API Key)
